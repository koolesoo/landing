Согласие на обработку персональных данных

Настоящим я, действуя свободно, своей волей и в своем интересе, выражаю согласие Анастасии Нерадовских, ИНН [ИНН] (далее — «Оператор»), на обработку моих персональных данных в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных».

1. Персональные данные

Оператор осуществляет обработку следующих персональных данных:

  • имя, указанное в профиле пользователя в Telegram;
  • никнейм (username) в Telegram;
  • сведения о взаимодействии пользователя с Telegram-ботом;
  • технические сведения и данные об использовании сайта, включая файлы cookie и сведения о действиях пользователя на сайте, получаемые посредством сервиса Яндекс Метрика.

Имя и никнейм пользователя в Telegram становятся доступны Оператору в случае, если пользователь самостоятельно переходит в Telegram-бот Оператора и начинает взаимодействие с ним.

2. Цели обработки персональных данных

Обработка персональных данных осуществляется в следующих целях:

  • обработка обращений и запросов пользователей;
  • предоставление пользователю запрошенных материалов, включая гайды;
  • запись пользователя на консультации, менторство и иные услуги;
  • связь с пользователем;
  • обработка и сопровождение заявок;
  • заключение и исполнение договоров на оказание услуг;
  • обеспечение работы Telegram-бота;
  • анализ работы сайта и улучшение его функциональности;
  • ведение статистики посещения и использования сайта.

3. Использование Telegram

При самостоятельном переходе пользователя в Telegram-бот и начале взаимодействия с ним Оператор получает доступ к данным Telegram-профиля пользователя, которые предоставляются Telegram в рамках взаимодействия с ботом, включая имя и никнейм (username).

Указанные данные используются Оператором для идентификации пользователя, обработки его запроса, предоставления запрошенных материалов, связи с пользователем и оказания услуг.

4. Использование Яндекс Метрики

На сайте используется сервис веб-аналитики Яндекс Метрика.

В рамках работы Яндекс Метрики могут обрабатываться технические сведения об устройстве и браузере пользователя, файлы cookie, сведения о посещении сайта и действиях пользователя на сайте, а также иные данные, необходимые для анализа использования сайта.

5. Действия с персональными данными

В рамках обработки персональных данных Оператор вправе осуществлять следующие действия:

  • сбор;
  • запись;
  • систематизацию;
  • накопление;
  • хранение;
  • уточнение (обновление, изменение);
  • извлечение;
  • использование;
  • обезличивание;
  • блокирование;
  • удаление;
  • уничтожение.

Обработка персональных данных может осуществляться с использованием средств автоматизации и без их использования.

6. Срок действия и отзыв согласия

Настоящее Согласие действует до достижения целей обработки персональных данных либо до его отзыва Пользователем, если иной срок не установлен законодательством Российской Федерации.

Пользователь вправе отозвать настоящее Согласие, направив обращение Оператору по электронной почте: [EMAIL].

После получения отзыва Оператор прекращает обработку персональных данных, если отсутствуют иные предусмотренные законодательством Российской Федерации основания для их обработки.

7. Обработка после отзыва согласия

В случае отзыва настоящего Согласия Оператор вправе продолжить обработку персональных данных без согласия Пользователя при наличии иных оснований, предусмотренных Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных».

8. Подтверждение согласия

Настоящее Согласие предоставляется Пользователем путем совершения действий, предусмотренных интерфейсом сайта и/или Telegram-бота, свидетельствующих о его намерении взаимодействовать с Оператором.

Переход пользователя с сайта в Telegram-бот сам по себе не означает предоставление каких-либо данных через сайт. Данные Telegram-профиля становятся доступны Оператору в рамках взаимодействия пользователя с Telegram-ботом.
