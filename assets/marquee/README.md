# Стандарт логотипов для карусели

## Как выглядит на сайте

| Параметр | Мобилка | Десктоп |
|----------|---------|---------|
| Высота слота | **44 px** | **52 px** |
| Ширина | авто по пропорциям файла | авто |
| Макс. ширина | ~152 px | ~176 px |

Все логотипы масштабируются одинаково: `height: 100%`, `object-fit: contain`.

## Как готовить файл

**Формат:** PNG с прозрачным фоном (не чёрная подложка, если фон сайта тёмный).

**Холст для экспорта:**

- Высота: **120 px** (или **240 px** для Retina — сайт сам уменьшит)
- Ширина: по пропорциям бренда, обычно **120–400 px**
- Логотип должен занимать **90–100% высоты** холста — без больших пустых полей сверху/снизу

**Эталоны в этой папке:** `logo-sber.png`, `logo-tbank.png` — ориентируйся на них по «плотности» и размеру.

## Частые ошибки

| Проблема | Результат |
|----------|-----------|
| Много прозрачного padding вокруг | Логотип кажется мелким |
| Только символ без текста, когда у соседей полный логотип | Альфа выбивается по масштабу |
| Чёрный прямоугольник в PNG | Видна «коробка» на тёмном фоне |
| Огромный файл (3000+ px) с мелким гербом по центру | На экране всё равно мелко — обрежь холст |

## Имена файлов

Клади готовый файл в `assets/marquee/` и пропиши имя в `PLACEMENTS_LOGOS` / `EXPERT_LOGOS` в `index.html`.

После замены файла обнови `MARQUEE_ASSET_VERSION` в `index.html` (функция `initLogoMarquees`), чтобы браузер подтянул новую версию.

## Быстрая проверка в Figma / Photoshop

1. Создай фрейм **120 × 120 px** (квадрат) или **120 × 200 px** (горизонтальный).
2. Вставь логотип, масштабируй до **~110 px** по высоте.
3. Экспорт PNG @1x → положи в `assets/marquee/`.
4. Hard refresh страницы (Cmd+Shift+R).
